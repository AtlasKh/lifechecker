# ✨ Мой год — календарь жизни

Telegram Mini App: каждый вечер 5 быстрых вопросов → день окрашивается от красного к зелёному → год складывается в картину. Бот присылает итоги недели, месяца и года.

```
lifecal/
├── docs/index.html      ← само приложение (GitHub Pages)
└── worker/
    ├── worker.js        ← бэкенд + бот (Cloudflare Workers)
    ├── schema.sql       ← таблицы базы (Cloudflare D1)
    └── wrangler.toml    ← конфиг, если деплоишь из терминала
```

**Всё бесплатно:** GitHub Pages (фронт) + Cloudflare Workers и D1 (бэкенд, база, расписание). Сервер держать не нужно.

---

## Что нужно от тебя — 5 шагов (~30 минут)

### Шаг 1. Создать бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username.
2. Сохрани **токен** (вида `123456:ABC...`). Никому его не показывай и не коммить в GitHub.

### Шаг 2. Выложить приложение на GitHub Pages
1. Создай на GitHub репозиторий `lifecal` (можно публичный).
2. Залей туда содержимое этой папки.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs`** → Save.
4. Через минуту приложение будет по адресу `https://ТВОЙ_НИК.github.io/lifecal/`.
   Открой в браузере — оно уже работает (данные пока хранятся только в браузере).

### Шаг 3. Бэкенд на Cloudflare (через сайт, без терминала)
1. Зарегистрируйся на **dash.cloudflare.com**.
2. **Storage & Databases → D1 → Create** → имя `lifecal`.
   Открой базу → вкладка **Console** → вставь всё из `worker/schema.sql` → Execute.
3. **Compute (Workers) → Create → Hello World** → имя `lifecal` → Deploy.
   Потом **Edit code** → замени весь код содержимым `worker/worker.js` → Deploy.
4. В воркере **Settings → Bindings → Add → D1 database**: имя переменной `DB`, база `lifecal`.
5. **Settings → Variables and Secrets**, добавь:
   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | Secret | токен из шага 1 |
   | `WEBHOOK_SECRET` | Secret | любая длинная случайная строка, например `k8Fq2m...` (только буквы/цифры) |
   | `WEBAPP_URL` | Text | `https://ТВОЙ_НИК.github.io/lifecal/` |
   | `REPORT_HOUR` | Text | `20` — во сколько присылать отчёты (по времени пользователя) |
   | `DAILY_REMINDER` | Text | `1` — напоминать вечером, если день не отмечен (`0` — не напоминать) |
6. **Settings → Trigger Events → Add → Cron Triggers** → `0 * * * *` (каждый час).
7. Скопируй адрес воркера, вида `https://lifecal.ТВОЙ-АККАУНТ.workers.dev`.

### Шаг 4. Связать всё вместе
1. В `docs/index.html` найди строку `const API_URL = '';` и впиши адрес воркера:
   `const API_URL = 'https://lifecal.ТВОЙ-АККАУНТ.workers.dev';` → закоммить.
2. Открой в браузере один раз:
   `https://lifecal.ТВОЙ-АККАУНТ.workers.dev/setup?key=ТВОЙ_WEBHOOK_SECRET`
   Должен прийти JSON, где везде `"ok": true`. Это подключит вебхук, команды и кнопку «Мой год» в меню бота.
3. (Опционально) В @BotFather: `/newapp` → выбери бота → укажи тот же URL. Тогда появится красивая ссылка `t.me/твой_бот/app`.

### Шаг 5. Проверить
Напиши боту `/start` → нажми **«✦ Открыть мой год»** → ответь на 5 вопросов. Потом `/week` — придут итоги.

## Как это работает
- **Опросник:** 5 вопросов, на каждый «Нет / Отчасти / Да» (0 / 0.5 / 1). Можно тапать или свайпать карточку (вправо — да, влево — нет). Оценка дня — среднее, цвет — плавный градиент 🟥 → 🟧 → 🟩.
- **Календарь:** неделя (с разбивкой по вопросам), месяц, год (12 мини-месяцев). Тап по дню — детали и редактирование. Можно заполнить пропущенные прошлые дни.
- **Статистика:** средний балл, динамика по дням/месяцам, средние по каждому вопросу, лучший день, лучшая серия.
- **Бот:** итоги недели (вс вечером), месяца (последний день), года (31 декабря), плюс вечернее напоминание. Команды: `/today`, `/week`, `/month`, `/year`, `/stop`, `/resume`.
- **Данные:** сначала сохраняются на устройстве (работает даже без сети), затем отправляются на сервер. Сервер проверяет подпись Telegram, поэтому чужие данные прочитать или подделать нельзя.

## Как менять
- **Вопросы:** массив `QUESTIONS` в начале скрипта в `docs/index.html` **и** в `worker/worker.js` (id должны совпадать). Старые ответы сохранятся.
- **Цвета:** переменные в `:root` в начале `<style>` и массив `STOPS` (градиент дня).
- **Время отчётов:** переменная `REPORT_HOUR`.

## Путь к отдельному приложению
Фронтенд — обычная веб-страница без сборки, а Telegram используется только для входа и вибро-отклика. Дальше:
1. **PWA** — добавить `manifest.json` и service worker → устанавливается на телефон с сайта.
2. **Capacitor** — обернуть ту же страницу в iOS/Android-приложение.
3. **Вход вне Telegram** — добавить в воркер вход через Telegram Login Widget или email; API и база останутся теми же.

Когда интерфейс разрастётся (настройки, свои вопросы, заметки к дню), стоит перенести фронт на Vite + React/Svelte — структура данных и API для этого уже готовы.
